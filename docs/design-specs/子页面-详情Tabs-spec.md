# 页面架构结论：详情层 Tab 页（/work、/projects/:slug、/path、/about、/contact）

- 页面类型：
  - 首页之外的独立路由详情页，全部为**普通自然滚动**页面（不启用 scroll-snap）
- 共同框架：
  - 顶部沿用跨页 `SiteNav`（当前 Tab 黄底高亮）
  - 页面顶部统一 PageHeader：返回首页入口 + 页面标题 + 一句导语
  - 内容居中容器，PC 最大宽 1080-1120px，纸底 `#F4F1EA`
  - 底部统一 Footer：联系信息 + 简历下载 + 回到首页
- 共同样式：
  - 沿用首页全部新粗野主义 Token（2-4px 黑描边、4/6/8px 硬阴影、平涂色块、0-4px 圆角）
  - 详情页视觉密度低于首页：以白卡片承载长文，饱和色只用于标签、引述、关键指标
  - 所有图片 / 截图 2-3px 黑边 + 硬阴影

## 1. /work · 作品列表页

- 页面职责：
  - 首页 C1 的展开版，承载全部案例入口与分类筛选
- 页面结构（自上而下）：
  1. PageHeader：`WORK / 作品` + 导语“3 个项目，覆盖 Agent 工作流、数据智能化与个人实践”
  2. Featured 案例大卡（最强 AI 项目，横向：左截图右文案，黄底）
  3. 标准案例卡列表（2 张起，纵向排列，白底粗边卡）
  4. （可选）更多实践小卡网格：文章、产品拆解、demo
- 卡片信息（倒金字塔）：
  - 结果先行标题 → 问题（带数字）→ 我的角色 → AI 设计点标签 → 工具 badge → `阅读案例 →`
- 交互：
  - 整卡点击进入 `/projects/:slug`；支持锚点定位（首页 C2 证据指针跳入时定位到对应卡并高亮一次）
  - 不做复杂筛选器；项目 ≤6 个时只保留类型标签
- 避坑：
  - 宁缺毋滥，不凑项目数；每张卡必须有真实结果或真实产出物

## 2. /projects/:slug · 案例详情页

- 页面职责：
  - 全站深度证据核心，按倒金字塔讲清一个项目
- 页面结构（固定六段，支持锚点目录）：
  1. Overview：项目名、角色、时间、团队规模；一句话结果 + headline 指标；背景 2-3 句
  2. Problem：业务/用户问题，尽量给基线数据与约束条件（时间、资源、合规）
  3. Approach & Decisions：调研方法、关键洞察、备选方案、为何选它；**AI 项目必须写清模型 / Agent 架构选型与 trade-off**
  4. Evals：如何评估 AI 质量（评测集、指标、基线对比、bad case 处理）——AI PM 高信号段
  5. Outcome：前后对比数字、产出物、用户反馈；未达标也如实写
  6. Learnings：1-2 段“重来会怎么做”，具体不鸡汤
- 版式：
  - 左侧粘性小目录（六段锚点），右侧长文；移动端目录收成顶部横滑 chips
  - 关键截图 / 流程图用粗边框图卡；引述结论用黄底黑边 blockquote
  - 文末：产物链接（脱敏文档 / demo）+ 上一/下一案例 + `返回作品列表`
- 交互：
  - 外链新窗口打开；脱敏文档可嵌弹层预览
- 避坑：
  - 禁止“使用 AI 提效 XX%”式空话；每个决策写清“选了什么、放弃了什么、为什么”
  - 涉密内容脱敏，不编造数据

## 3. /path · 履历详情页

- 页面职责：
  - 完整职业路径、教育、指标总览、产物陈列、简历下载
- 页面结构：
  1. PageHeader：`PATH / 履历` + 下载简历主按钮
  2. 指标条：3-4 个大数字贴纸（与首页 C3 数据一致）
  3. 完整时间线：每段经历一张粗边卡，包含公司/团队、角色、时间段、2-3 条成果、领域标签
  4. 教育卡：硕士 · 学校 · 专业 · 在校亮点 1-2 条
  5. `#artifacts` 产物陈列架：脱敏 PRD、AI 评测集、BI 看板、产品分析等，缩略图 + 名称 + 类型标签 + 外链/弹层
  6. CTA：`下载简历 PDF` + `联系我`
- 版式：
  - 左侧 3px 黑实线时间轴，节点黑边方块 / 橙红实心块
  - 产物架 2-4 列网格，白底 3px 黑边 6px 硬阴影
- 避坑：
  - 成果以数据化短句为主，不贴岗位职责；产物必须脱敏且可打开

## 4. /about · 关于页

- 页面职责：
  - 首页 C5 的展开：更完整的第一人称叙事 + 摄影画廊
- 页面结构：
  1. PageHeader：`ABOUT / 关于我`
  2. 长文自我介绍（400-700 字，分 3-4 个小标题）：
     - 职业路径：为什么从数据平台走到 AI 产品
     - 我相信什么：产品方法论与工作信念
     - 当下关注：AI Agent、人机协同、数据智能化
     - 工作之外：摄影 / 篮球 / 影视如何反哺职业（审美、体能、叙事）
  3. 摄影画廊：6-12 张作品，粗边贴纸网格，点击大图查看（lightbox 也保持粗边样式）
  4. 兴趣小卡：篮球、影视各一张，各一句话
  5. CTA：`联系我` / `下载简历`
- 版式：
  - 长文用白底粗边卡；画廊允许 ±2-3° 贴纸旋转
- 避坑：
  - 第一人称、具体、有态度；不写成第三人称新闻稿

## 5. /contact · 联系页

- 页面职责：
  - 集中所有可达联系渠道，降低联系摩擦
- 页面结构：
  1. PageHeader：`CONTACT / 联系`
  2. 一句行动号召（同首页 C6）
  3. 联系渠道大按钮列表（黑边硬阴影）：
     - 邮箱（`mailto:`）
     - LinkedIn / 即刻 / GitHub / 微信（微信用弹层展示二维码，二维码图片加黑边）
     - 简历下载
  4. 可选：当前状态标签（如“开放交流 / 看机会中”），绿底黑边贴纸
- 避坑：
  - 不放复杂表单；所有链接实测可达；不暴露私人电话/住址

## 6. 全局代码生成约束

- 详情页共用 SiteNav / Footer / PageHeader 组件，Token 与首页完全一致
- 详情页禁用 scroll-snap；长文行宽 ≤72ch，正文行高 1.75-1.9
- 所有路由静态生成（SSG），图片 lazy loading，保证 SEO 与 Lighthouse ≥90
- `/projects/:slug` 内容数据化（如 `content/projects/*.mdx`），新增案例不改代码
- 移动端：目录转横滑 chips、时间线转纵向单列、产物网格转单列/双列
- 语义化与 SEO：每页独立 title/description/OG；案例页补 Article 结构化数据
