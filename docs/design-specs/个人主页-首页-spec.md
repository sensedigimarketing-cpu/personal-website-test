# 页面架构结论：首页 = 整屏滑动的“个人 zine 封面”（摘要层）

- 页面类型：
  - 公开个人主页的首页 `/`
  - 纵向整屏滑动（CSS scroll-snap）的沉浸式章节流
- 页面职责：
  - 用 7 个整屏章节在一次滑动中讲完“是谁 / 信什么 / 做过什么 / 怎么联系”
  - 只承载高信号摘要；所有深度内容通过每章「查看详情 →」进入独立 Tab
- 页面布局结构：
  - 跨页面顶部导航（Tab 切换）
  - 7 个全屏 chapter + 右侧章节 dots
  - 每章内部居中容器（PC 最大宽 1120px）
  - 无传统页脚（尾屏即 CTA）
- 页面样式规范：
  - 整体风格：新粗野主义（Neo-Brutalism）——粗黑描边、硬偏移阴影、高饱和撞色、超粗字体
  - “克制版”定位：每章一个观点、一屏讲完，色彩像翻 zine 一样逐章切换但保持阅读清晰
  - 全站禁用渐变、毛玻璃、模糊柔光投影；深度仅由黑色描边与硬偏移阴影表达

## 1. 页面定位

- 用户身份定位：
  - 数据平台背景的产品经理
  - 正在把 AI Agent / AI 工作流落到真实产品里的复合型产品人
- 首页一句话：
  - `数据平台出身的产品经理，正在把 AI Agent 变成真实可用的产品能力`
- 首页任务：
  - 不是“网页版简历”，而是一次有节奏的、滑完即懂的个人品牌陈述
  - 每个被勾起兴趣的点，都有对应 Tab 可以立刻深挖

## 2. 视觉系统

### 2.1 三条硬规则（不可违反）

1. 粗黑描边：所有卡片、按钮、标签、图片外框统一 2-4px 纯黑（`#000000`）实线
2. 硬阴影：`box-shadow` 零模糊纯黑偏移（`4/6/8px 同值 0 #000`），贴纸质感
3. 平涂色块：一表面一纯色，禁止渐变、半透明叠色、blur

### 2.2 配色 Token

| 角色 | 色值 | 首页用途 |
| --- | --- | --- |
| 墨黑 | `#000000` | 描边、硬阴影、主文字、C6 底色 |
| 纸底 | `#F4F1EA` | C0 / C2 / C4 暖米背景 |
| 卡片白 | `#FFFFFF` | C5 背景、卡片面 |
| 品牌黄 | `#FFD400` | C1 底色、主 CTA、关键词高亮 |
| 电光蓝 | `#2F6BFF` | C2 辅助、AI 标签、链接 |
| 荧光绿 | `#3DDC84` | C3 指标、正向成果 |
| 亮粉 | `#FF6BB5` | C5 兴趣色 |
| 橙红 | `#FF7A3D` | 时间线节点、强调 |
| 紫 | `#B57BFF` | 次级标签 |

### 2.3 字体

- 英文标题：`Space Grotesk` 700；封面大标题可用 `Archivo Black`
- 中文：`Noto Sans SC` / 思源黑体（标题 700/900，正文 400/500）
- 等宽：`Space Mono`，用于章节编号、年份、标签
- 标题用 `clamp()` 随视口缩放；关键词加黄色平涂马克笔高亮

### 2.4 形状与交互语言

- 圆角 0-4px（最大 8px），宁方勿圆
- Hover：元素 -2px/-2px，阴影 +2px；Active：+2px/+2px，阴影归零
- 过渡 0-150ms；禁止淡入淡出、视差劫持、持续漂浮
- 几何装饰：星形、实心圆、锯齿线、手绘箭头（黑边 SVG）
- 图片统一 3px 黑边 + 硬阴影；贴纸微旋转 ±2-3° 只用于图片/徽章

## 3. 滑动机制（技术与交互硬约束）

### 3.1 断点策略

- 桌面（≥1024px 且高度 ≥640px）：
  - 滚动容器 `h-[100svh] overflow-y-scroll scroll-snap-type: y mandatory`
  - 每章 `h-[100svh] scroll-snap-align: start`，一屏一章
- 移动 / 矮屏（<1024px 或高度 <640px）：
  - snap 降级为 `none`（自然滚动），章节改为 `min-h-[100svh]` 且允许增高
  - 隐藏右侧 dots 与下滑提示，靠自然滑动浏览
- 必须处理：iOS 用 `100svh` 防地址栏遮挡；横屏矮高度走降级分支

### 3.2 导航辅助

- 右侧固定 dots（桌面端）：7 个黑边方块/圆点，当前章填色，hover 展开章节名 tooltip，点击平滑滚到该章
- C0 底部中央下滑提示：黑边胶囊「SCROLL」+ 向下箭头，进入 C1 后淡出（仅 opacity 且 ≤150ms）
- 支持键盘 ↑ ↓ / PageUp PageDown / Space 切章；Tab 键可正常聚焦章内链接
- `@media (prefers-reduced-motion: reduce)`：关闭一切位移动效，snap 降为 proximity
- 实现：纯 CSS scroll-snap + 极轻量 IntersectionObserver 同步 dots，禁止 fullPage.js 等劫持滚动方案
- 所有章节常驻 DOM（SEO 可索引），不用虚拟化 / display:none

### 3.3 一屏完整性

- 每章内容必须在视口内完整呈现，禁止章内滚动条
- 内容预算：标题 1 行、说明 ≤2 行、卡片 3-4 个；超出时减文案不减体验
- 11-13 寸笔记本（约 768px 高）下逐章验收不溢出

## 4. 章节清单及详细定义

### C0 · COVER（封面）

- 底色：纸底 `#F4F1EA`
- 业务功能：3 秒内完成定位，给出“向下滑”和“看作品”两个动作
- 内容：
  - 等宽小标：`PRODUCT MANAGER · DATA PLATFORM → AI AGENT`
  - 超大主标题（2-3 行）：姓名/英文名 + 定位句，关键词黄底高亮
  - 副标题 1 句：价值主张
  - 信号贴纸 3 枚：硕士 / 大厂数据平台 / AI Agent 实践（黑边硬阴影，各填一色）
  - 头像贴纸：3-4px 黑边 + 8px 硬阴影，旋转 -2°
  - 主按钮：`查看作品 →`（跳转 `/work`，黄底黑边）；次按钮：`联系我`（白底黑边）
  - 底部黑底跑马灯：`PRODUCT MANAGER ✳ DATA PLATFORM ✳ AI AGENT ✳ ...`
  - 下滑提示：SCROLL ↓
- 避坑：
  - 不放长履历、不放社交图标群；主按钮只有一个

### C1 · WORK TEASER（精选作品速览）

- 底色：品牌黄 `#FFD400`（全章平涂，视觉第一高潮）
- 业务功能：用 3 张迷你卡在 10 秒内给出最强证据
- 内容：
  - 章节头：等宽编号 `01 / SELECTED WORK` + 超粗标题“做过什么”
  - 3 张横向并排迷你卡（白底 3px 黑边 + 6px 硬阴影）：
    - 卡 1 视觉缩略（2px 黑边）+ 结果先行标题（如“将 XX 流程从 X 压缩到 Y”）
    - 卡 2 / 卡 3 同结构，三个项目分别代表 Agent 工作流 / 数据×AI / 个人 side project
    - 每卡一行：我的角色 + 工具 badge（Trae Codex / Claude / 墨刀 / BI）
  - 底部按钮：`查看全部作品与案例 →`（跳 `/work`）
- 交互：整卡可点 → `/projects/:slug`；hover 按压反馈
- 避坑：
  - 每卡文案不超过 40 字；无结果数字时用产出物短句，不编造

### C2 · APPROACH（工作方式速览）

- 底色：纸底；标题区一块电光蓝平涂贴纸
- 业务功能：证明成果可复制；每条能力挂证据指针
- 内容：
  - 章节头：`02 / HOW I WORK`
  - 3 张方法卡横排（A/B/C 黑边方块编号）：
    - A 选对问题：需求调研、场景拆解——“先排除伪需求，再谈方案”
    - B 数据驱动：指标体系、BI 分析——“用数据验证判断，而不是支撑立场”
    - C AI 产品化：Agent 工作流、Prompt 与评测——“像设计功能一样设计 AI 行为”
  - 每卡底部一行证据指针：`→ 证据：作品 01 的评测体系`（点击跳 `/work`）
  - 工具不独立陈列，作为 badge 挂在卡上
- 避坑：
  - 无证据指针的能力宣称不允许出现；不写“沟通能力强”类无信号词；无进度条

### C3 · PROOF（指标 + 产物速览）

- 底色：荧光绿 `#3DDC84`（全章平涂，第二高潮）
- 业务功能：数字与可检视产物双重背书
- 内容：
  - 章节头：`03 / PROOF`
  - 上排 3-4 个超大数字贴纸（黑边硬阴影白/黄面）：
    - 【待填真实数字】项目数 / 提效比例 / 服务规模；没有可靠数字则降级为成果短句贴纸
  - 下排 3-4 个产物小贴纸（PRD / AI 评测集 / BI 看板 / 产品拆解）：
    - 黑边白底小卡 + 图标 + 名称，点击跳 `/path#artifacts`
  - 底部文字链：`查看完整履历与全部产物 →`（跳 `/path`）
- 避坑：
  - 数字必须真实；产物全部脱敏，至少准备 2 个

### C4 · PATH（履历一行流）

- 底色：纸底
- 业务功能：15 秒建立背景可信度，深度交给 /path
- 内容：
  - 章节头：`04 / PATH`
  - 2-4 行履历列表，每行：等宽年份 + 公司/团队类型 + 角色 + 一条数据化成果
  - 行之间 3px 黑实线分隔，行首黑边方块节点
  - 教育一行：硕士 · 学校 / 专业【待填】
  - 右下按钮：`完整履历与简历 →`（跳 `/path`）
- 避坑：
  - 每行只有一条成果，不堆职责；总高度必须一屏放得下

### C5 · ABOUT（人的侧写）

- 底色：卡片白 `#FFFFFF`，局部亮粉平涂块
- 业务功能：在证据之后补完“人”的形象
- 内容：
  - 章节头：`05 / ABOUT`
  - 左侧：第一人称 3-4 句短文（职业选择、当前关注 AI×数据×产品、工作信念）
  - 右侧：3 张摄影作品贴纸（3px 黑边 + 6px 硬阴影，±2-3° 旋转）
  - 底部兴趣 chips：摄影（Lightroom/Photoshop）· 篮球 · 影视，亮粉/紫填色
  - 文字链：`更多照片与我的故事 →`（跳 `/about`）
- 避坑：
  - 短文 ≤180 字；旋转只用于照片；整章占比克制

### C6 · CONTACT（黑底尾屏）

- 底色：墨黑 `#000000`（全章出血）
- 业务功能：全站唯一转化出口，强记忆收尾
- 内容：
  - 等宽小标：`06 / CONTACT`
  - 超粗大标题（白字，关键词可黄色高亮）：`有 AI 产品问题想聊？`
  - 副句：`或有合适的机会，欢迎找我。`
  - 3 个粗边按钮横排（阴影用白色）：邮箱 · LinkedIn/即刻/微信 · 下载简历
  - 底部小字：姓名 / 年份 / `回到顶部 ↑`
- 避坑：
  - 联系方式真实可达；不做复杂表单；按钮不超过 4 个

## 5. 全局组件清单

- `SiteNav`：跨页顶部 Tab（首页 / 作品 / 履历 / 关于 / 联系 + 下载简历）
- `ChapterShell`：全屏章节容器（编号、底色槽位、内容槽、详情入口槽位）
- `ChapterDots`：右侧章节指示（仅桌面端）
- `ScrollHint`：C0 下滑提示
- `StickerTag`：黑边硬阴影信号贴纸 / 兴趣 chip
- `Marquee`：CSS transform 跑马灯（不吃 JS 主线程）
- `TeaserCard`：C1 作品迷你卡
- `MethodCard`：C2 方法卡（含证据指针）
- `MetricSticker`：C3 大数字贴纸
- `ArtifactChip`：C3 产物贴纸
- `PathRow`：C4 履历行
- `PhotoSticker`：C5 摄影贴纸
- `BrutalButton`：主 / 次 / 黑底白阴影三态按钮

## 6. 关键交互闭环

- 滚轮 / 触摸 / 键盘均可逐章滑动，dots 实时高亮
- dots 点击跳章；C0 主按钮 → `/work`；C0 次按钮 → 滚到 C6 或 `/contact`
- C1 卡片 → `/projects/:slug`；C1 底部按钮 → `/work`
- C2 证据指针 → `/work`（带锚点定位对应案例）
- C3 产物贴纸 → `/path#artifacts`；C4 按钮 → `/path`；C5 文字链 → `/about`
- C6 联系按钮一键跳转邮件 / 社媒 / 简历下载
- 顶部「下载简历」全站常驻可用

## 7. 全局代码生成约束

### 7.1 新粗野主义硬约束

- 描边只有 2 / 3 / 4px 纯黑实线；硬阴影只有 `4/6/8px 同值 0 #000` 三档，方向右下
- 禁止渐变、backdrop-filter、rgba 柔光；圆角 0 / 2 / 4px（最大 8px）
- 动效仅 0-150ms 位移与阴影变化；hover 上移阴影增大、active 下移阴影归零
- 每屏饱和色不超过 2-3 种；装饰旋转仅用于图片/徽章

### 7.2 滑动与工程约束

- 滚动行为由浏览器原生接管，禁止 wheel/touch 事件 `preventDefault`
- 桌面 mandatory snap、移动/矮屏自然滚动，双分支必须实测
- 每章一屏完整、无内部滚动；以 1280×800 与 390×844 两档为主验收尺寸
- 图片压缩 + lazy loading + 统一黑边
- 语义化：每个 chapter 一个 `<section aria-labelledby>`；dots 加 `aria-current`
- SEO：`title` / `description` / Open Graph / 结构化数据齐全；七章内容服务端可见
- 色块逐一核对 WCAG AA 对比度（黑字配黄/绿/纸底均满足，黑底白字满足）
- Tailwind Design Token 集中管理色板、描边、阴影（`shadow-brutal`、`border-ink`、各章 bg token），禁止散落魔法值

## 8. 待用户提供内容清单

- 姓名 / 英文名、头像、可公开联系方式（邮箱、LinkedIn/即刻/微信、简历 PDF）
- 3 个精选项目：结果标题 / 问题（尽量带数字）/ 角色 / AI 设计点 / 工具 / 产物链接
- 2-4 段履历：年份 + 公司类型 + 角色 + 一条成果；硕士学校与专业
- C3 指标条真实数字（没有则确认降级为成果短句）
- 2-4 个脱敏产物、3 张摄影作品

## 9. 分阶段落地

- Phase 1（MVP）：7 章首页（占位内容可先跑通滑动与降级）+ `/work` + 1 个案例页 + `/path` + `/about` + `/contact`
- Phase 2：补齐 3 个案例详情与真实数字、英文版
- Phase 3：文章 / 产品拆解、访问统计

## 10. 验收清单

- 架构：首页是否为整屏滑动；深度内容是否全部在 Tab；每章是否都有详情入口
- 滑动：桌面逐屏 snap、移动自然滚动、键盘可达、reduced-motion 降级、矮屏不溢出
- IA：第二屏是否为作品速览；方法卡是否都挂证据；指标是否真实
- 风格：无渐变 / 无模糊阴影 / 无毛玻璃 / 无柔和大圆角 / 无长时浮动动画
